Nasıl çalışır

Her şey telefonun içinde çalışır. Bilgisayara ya da internete hiçbir kapı açılmaz.

Termux — telefonun PowerShell'i. Gerçek bir Linux terminali: git, node, python…
Ubuntu (proot) — Termux'un içindeki küçük Ubuntu. Claude Code Android'de doğrudan çalışmadığı için burada çalışır. claude yazınca oraya otomatik geçilir.
Claude Code — "harness" dediğin şey bu: modeli dosyalarına ve terminaline bağlayan, komut çalıştırıp dosya düzenleyebilen program. PC'de nasıl çalışıyorsa burada da öyle çalışır.
Kumanda — bu panel. Termux'ta çalışır, Chrome'da açılır. Terminal sekmeleri, GitHub projeleri, dosyalar, önizleme. Sadece 127.0.0.1'e açıktır: telefonun dışından kimse bağlanamaz.
Projeler ~/projeler klasöründe durur. Termux, Ubuntu ve Claude aynı klasörü görür.

Her oturumda

Altın kurallar (hata yapmamak için)

  1. Projeleri ~/projeler'e klonla, telefon hafızasına (~/storage/shared) değil. Android orada dosya çalıştırmaya ve kısayol (symlink) oluşturmaya izin vermez; npm install ve git bozulur. Telefon hafızası sadece dosya alıp vermek için: indirilenlerden bir dosyayı projeye kopyala.
  2. Önce pull, sonra iş, sonra push. İki cihazda aynı anda düzenleme yapma.
  3. Claude izin sorduğunda oku. rm -rf, git push --force, git reset --hard görürsen ne yaptığını anlamadan onaylama.
  4. Doğrudan main'e değil, dala çalış önemli projelerde: git switch -c deneme. Bozulursa main sağlam kalır.
  5. Erişim anahtarını kimseyle paylaşma, ekran görüntüsünde görünmesin.
  6. Termux'u Play Store'dan güncelleme; kurduğun yerden (F-Droid/GitHub) güncelle.
  7. Bir şey ters giderse paniğe gerek yok: push edilmiş her şey GitHub'da güvende. Telefondaki kopyayı silip yeniden klonlayabilirsin.
